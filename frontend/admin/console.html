Gateway Console · Models & Pricing

模型与计价

上游实际提供的模型、准入白名单，以及作为计价中间层的开放平台参考价。
价目来自智谱开放平台（docs.bigmodel.cn）的公开定价页，那是另一个产品的账；本网关上游 ZCode 按 units 计额度、不按货币出账，所以一切「元」都是参考估算。
上游模型
只列上游实际提供的模型：实测常量 ∪ 号池权益推导，与白名单模式无关。圆点 = 号池额度，红标签 = 名单外。点击复制模型名。
是否被上游 3006 钉在某个号上属按号状态，账号卡片上能看到；本表不下这个结论。
模型白名单
策略口径：决定进入网关的请求放行哪些模型名。名单外的请求直接拒掉，不占账号。
白名单模式
manual（默认）只认手填名单；static 只认内置名单；dynamic 只认账号额度里实际列出的模型；hybrid = 内置 ∪ 额度派生。上游真回 3006 时把「这个号不含这个模型」钉在该号上（默认 7 天自动失效），选号直接跳过它，不会把号判废。
手填名单（每行一个）
只按名字放行，别名与大小写自动归一到官方写法。留空 = 不拦任何模型名，防止一次误清空把网关锁死。
计价参考
三层优先级：内置 < 拉取 < 后台覆盖。单价单位元/百万 token，仅供估算参考，非 ZCode 账单。

Gateway Console · System

系统参数

登录口令与后台调度周期。除口令外各项修改后即时生效，无需重启。
登录口令
用于登录此管理后台。修改后需用新密码重新登录；输入框显示掩码，未改动保存不会覆盖原值。
当前仍是默认口令，生产环境请立即更换。
调度与容灾
三个周期各自独立，设为 0 即关闭该项的自动轮次（手动入口仍可用）；另有一项并发上限。
额度刷新间隔（秒）
后台自动刷新各账号额度与状态的周期。默认 1800（30 分钟）。
单账号并发上限
每个账号同时处理的最大请求数；某账号并发满时自动切下一个账号。0 = 不限制。默认 2。
套餐自动领取轮（秒）
周期对全部 JWT 账号执行活动套餐领取（激活上报 + 查询 + 领取）。默认 3600（1 小时）。
价目拉取间隔（秒）
条件 GET 公开定价文档站，只读、不携带任何账号身份。默认 0（关闭）——价目属参考层，没必要周期打别人的站。
